# Titanic Survivors - Exploratory Data Analysis (EDA)

This project analyzes the Titanic dataset to uncover the key factors that influenced passenger survival rates during the disaster. 

### Key Insights:
* **Gender & Class:** 1st Class females had the highest survival rate (96.8%), while 3rd Class males had the lowest (13.5%).
* **Age Groups:** Children (0-12 years) were heavily prioritized during the evacuation, resulting in the highest survival rate (58.0%) among all age groups.

The analysis demonstrates that socio-economic status and the "women and children first" protocol were the defining factors in surviving the Titanic.
